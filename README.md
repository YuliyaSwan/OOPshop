# Ядро для интернет-магазина
## Описание:
В проекты выделены классы: Категории и продукты. Инициализированы функции подсчета категорий и продуктов.
## Установка:
1. Клонируйте репозиторий
   ```
   git clone https://github.com/YuliyaSwan/OOPshop.git
   ```
2. Установите зависимости
   ```
   pip install -r requirements.txt
   ```
3. Установите Pytest
   ```
   poetry add --group dev pytest
   ```
4. Установите Code coverage для %-ки проверки кода
   ```
   poetry add --group dev pytest-cov
   ```


## Использование:
1. В модуле **utils** происходит чтение данных из json-файла и создание объектов - категории и продукты.
2. В модуле **OOP_16_1**:
   - созданы 2 класса с атрибутами,
   - добавлены геттер и сеттер для приватного атрибута **price**,
   - добавлен геттер для приватного атрибута **products**,
   - реализован класс-метод **new_product()**,
   - реализован метод **add_product()**,
   - добавлена возможность складывать продукты для получения общей стоимости всех товаров на складе,
   - добавлена возможность подсчета общего количество товаров по категориям,
   - созданы два класса наследников класса *Product* - *Smartphone* и *LawnGrass*,
   - классы *Smartphone* и *LawnGrass* расширены атрибутами,
   - доработана функциональность сложения продуктов только из одинаковых классов,
   - доработан метод по добавлению продуктов.
3. В модуле **test_OOP_16_1** написаны тесты, которые проверяют:
   - корректность инициализации объектов классов,
   - подсчет количества продуктов,
   - подсчет количества категории
   - корректность изменения цены продукта,
   - добавление нового продукта,
   - корректность вывода строкового значения классов,
   - правильность подсчета всех товаров на складе,
   - подсчет общей стоимости всех товаров на складе.
